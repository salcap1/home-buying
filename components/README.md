# `components`

New product UI lives here. Prefer these over another one-off class in `app/page.tsx`. Theme comes from `lib/brand` CSS variables.

Installed in `components/ui/`:

| Use | Component |
|---|---|
| Actions | `Button` |
| Fields | `Input`, `Textarea`, `Label`, `Checkbox`, `Select` |
| Surfaces | `Card`, `Separator` |
| Data | `Table`, `Badge` |
| Overlay | `Dialog`, `Tooltip` |
| Layout | `Tabs` |

Maps stay on Leaflet + `maps.css`. Do not invent a second button or dialog style.
